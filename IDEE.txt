Grundidee: Ein Board das im Systemtray lebt und eine Promptbibliothek darstellt, aber leichter als PromptManager. Nach Kategorien sortierbare prompts workflows skills rollen agenten, die mit einem Klick in den Zwischenspeicher kopiert werden. Über Systemtray öffnen von Fenster. Import aus PromptManager möglich aber nur den aktuellsten Prompt. Es soll sehr leicht bleiben. Rechtsklick prompt / skill / workflow / Agent / roll Agent -> können mit rechtsklick auf materialisieren auf dem Desktop materialisiert werden als .md File. Ordnung nach Art, NAMEN (Immer groß geschrieben, mit diesem wird auch materialisiert), Änderungsdatum. Direkt editierbar. Automatische Speicherung. Bei Veränderung und erneuter Materialisierung wird alte Desktop Datei überschrieben, Bestätigung hierfür im Default unterdrückt. Unter Einstellungen kann materialisierungsort geändert werden, Default ist Desktop. Import von C:\Users\User\OneDrive\.TOPICS\.SOFTWARE\DATA\REL-PUB_ExplorerPro_SUITE möglich. Umgekehrt in C:\Users\User\OneDrive\.TOPICS\.SOFTWARE\DATA\REL-PUB_ExplorerPro_SUITE aufnehmen import möglichkeit aus Prompt-Board.
