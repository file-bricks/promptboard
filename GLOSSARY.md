# GLOSSARY.md - Begriffe

| Begriff | Bedeutung |
|---|---|
| **Board** | Die sichtbare Arbeitsoberfläche des Tools, über die Einträge gefiltert, bearbeitet und genutzt werden. |
| **Library Item** | Ein einzelner Eintrag in PromptBoard, z. B. ein Prompt, Skill oder Workflow. |
| **Materialisierung** | Das Ausgeben eines Eintrags als `.md`-Datei an einen Zielpfad. |
| **Tray Shell** | Der Teil der Anwendung, der im Systemtray lebt und das Hauptfenster öffnet. |
| **Adapter** | Eine klar getrennte Schnittstelle zu Fremdformaten oder anderen Tools wie ExplorerPro. |
| **Latest-only Import** | Ein Importmodus, bei dem aus einem Fremdmanager nur der aktuellste Prompt übernommen wird. |
| **ExplorerPro-Brücke** | Geplanter Import-/Austauschpfad zu `DATA/REL-PUB_ExplorerPro_SUITE`. |
| **Leichtgewichtig** | Im Projektkontext: wenig Klickpfade, wenige Abhängigkeiten, lokale Datenhaltung und bewusste Begrenzung des Funktionsumfangs. |
