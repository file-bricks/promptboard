Short Description:
Локальная утилита в трее для промптов, навыков, процессов, ролей и агентов.

Description:
PromptBoard — лёгкая настольная утилита с приоритетом офлайн-работы для многоразовых блоков LLM. Она хранит промпты, навыки, рабочие процессы, роли и агентов локально, обеспечивая быстрый доступ из системного трея, глобальные горячие клавиши, интерактивную подстановку переменных (`{{name}}`), интерфейс на 6 языках (`DE`, `EN`, `ES`, `ZH`, `JA`, `RU`) и экспорт в `.md`/`.txt` без обязательного облака.

- Меню системного трея с группировкой по категориям и копированием в один клик
- Глобальные горячие клавиши для окна и последнего использованного элемента
- Доступная навигация с клавиатуры, подсказки и метки для скринридеров
- Адаптеры обмена библиотеками для ProfiPrompt и ExplorerPro
- Полностью офлайн-работа: без учётных записей, внешних API и телеметрии
