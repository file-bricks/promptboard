Short Description:
Local tray tool for prompts, skills, workflows, roles, and agents.

Description:
PromptBoard is a lightweight, offline-first desktop utility for reusable LLM building blocks. It keeps prompts, skills, workflows, roles, and agents local, offers quick system tray access, global hotkeys, interactive `{{name}}` placeholder prompts, a live 6-language UI (`DE`, `EN`, `ES`, `ZH`, `JA`, `RU`), and clean Markdown materialization (`.md` / `.txt`) without mandatory cloud sync.

- Fast category-grouped system tray menu with one-click clipboard copy
- Global hotkeys to toggle window visibility and copy the last used entry
- Accessible keyboard navigation, tooltips, and screen-reader labels
- Adapters for ProfiPrompt and ExplorerPro library exchange
- 100% local offline operation: no accounts, no external APIs, no telemetry
